# 应用越来越复杂，Agent 怎样找到功能并正确操作？

[← 问题索引](README.md) · [按需上下文](../tags/按需上下文.md)

检索词：Feature Map、功能地图、用户路径、界面入口、共享记忆、操作易错点。

## 先看什么

- [R0004：pstack 指南 Pt. 1](../resources/R0004/README.md)，定位 `Keep agents smart with Feature Maps`：用总览连接细节，写清功能含义、用户视角入口、控制命令和易错点；随应用一起维护。
- [R0003：项目说明结构](../resources/R0003/README.md)，截图第 6 节：补充按任务触发读取关键文件的思路。项目文档入口与界面功能地图相关，但并非同一份东西。

## 可以先试什么

以下是据材料归纳的待实践建议：选一个常被问到的功能，记录真实打开路径、状态前提和预期界面；已有自动化工具时再附对应命令。让 Agent 按记录完成一次查找，修正文档与实际产品不一致的部分。

## 还缺什么

只有文章示例，尚未为用户应用建立功能地图。账号权限、功能开关和界面版本会影响路径，不能把静态地图当作永不变化的事实。

补充仓库参考：[R0016：pstack](../resources/R0016/README.md)。看 Feature Map 生成与维护：初次生成跑通一个功能，维护时要求逐个功能有源码与实际运行覆盖。 本库未为用户项目实际生成或验证。
