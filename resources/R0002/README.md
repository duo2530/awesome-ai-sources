## 一句话说明

让 AI 做得更多，不只是更快：把任务提升到最终目标，使用专业方法深入验证，再引入其他领域的工具与视角。

## AI 摘要与要点

作者把使用 AI 的进取方向分成速度（Speed）、高度（Altitude）、深度（Depth）和广度（Range）。速度是以更短时间完成同样的工作，本文主要讨论另外三种。

| 方向 | 关键做法 | 正文中的例子 |
|---|---|---|
| 高度 | 从指定操作转向最终结果，并为持续工作准备数据、环境与验证能力 | 从制作季度汇报幻灯片，转向发现业务变化、支持决策，乃至设计更及时的审查方式 |
| 深度 | 使用专业人员实际采用的数据、工具和方法，检验假设并接受外部验证 | 用原始日志复核客户流失原因，用未见数据验证预测，而不只优化汇报措辞 |
| 广度 | 从任务要实现的动作出发，引入其他领域的方法 | 从“做一个演示文稿”转向分析、叙事、编辑与对抗性审查；强调执行专业方法而非模仿专家口吻 |

值得带走的做法：

- 先问“这个任务完成后，我真正希望发生什么”，再判断是否值得提高目标层次。
- 追问专业人员会从什么原始材料开始、使用什么工具，以及怎样证明结果正确。
- 当模型只改变用词而没有改变方法时，要求具体数据处理、分析或验证动作。
- 通过跨领域视角补充方法和盲点；不为了角色数量而制造多 Agent 表演。
- 持续自主工作的前提包括可用数据、工具、执行环境和反馈，不是只写一句更大的目标。

## 适用边界

- 本文是作者的方法建议与经验，不是比较不同策略效果的受控实验。
- “提高目标层次”不适合所有工作；作者也指出，它对某些创作任务未必同样有效。
- 文中建议设置极高目标并鼓励模型继续探索；这不证明目标物理可行，实践中仍需检查限制、证据与投入上限，不能把坚持误当成正确。
- “用外部评判者”可以落实为实际工具或验证流程，不必一律再启一个 Agent。
- 历史故事、心理学论据和文中外链未在本轮独立核验；本文摘要不把这些转述当作已验证事实。
- 原文内的提示词只作阅读材料，本轮没有执行、创建自主任务或接入数据工具。
