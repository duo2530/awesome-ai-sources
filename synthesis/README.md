# 综合

[← 首页](../README.md) · [全部内容](../resources/README.md) · [带着问题找参考](../problems/README.md)

综合页把多条资料归纳成“当前认识”，并随新资料修订。它与问题页的分工：问题页从“用户会怎么问”出发给出阅读顺序，综合页从“主题”出发给出判断、对照与分歧。

只有同一主题已有多条资料、且它们之间存在真实取舍或冲突时才建页；单篇资料的内容留在对应条目，不为凑目录建页。

综合页的结论与条目一样受证据约束：项目自述不等于已验证，本库归纳不等于作者主张；修订时保留原判断的依据，不静默覆盖。
