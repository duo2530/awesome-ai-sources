# 外部验证

[← 标签](README.md) · [问题索引](../problems/README.md)

同义检索词：外部评估、独立验证、outside judge、测试入口。工具测试与独立评审是不同方式，不要求同时具备。

- [R0002：How to be more ambitious](../resources/R0002/README.md)：Depth 部分强调外部反馈，并给出未见数据检验预测的例子；不是仅让同一模型自我认可。
- [R0003：项目说明结构参考](../resources/R0003/README.md)：截图第 7 节建议在项目说明中写清单元测试与 Mock 约定，为任务结束后的验证提供入口；未给出独立评审流程。
- [R0004：pstack 指南 Pt. 1](../resources/R0004/README.md)：提供 Agent 可调用的应用操作与检查工具，取得运行反馈与截图证据；不等于独立评审。

相关问题：[专业分析怎样证明结果可靠？](../problems/让AI做专业分析.md)


- [R0005](../resources/R0005/README.md)：测试、媒体、决策日志与迁移前后对照形成审阅证据。
- [R0007](../resources/R0007/README.md)：以运行证据积累信任；字幕未核对画面。


- [R0008：端到端业务需求专家 Agent](../resources/R0008/README.md)：独立环境中取接口、日志和监控证据，覆盖正例、反例与回归。


- [R0009：端到端交付2.0](../resources/R0009/README.md)：独立会话和工作区读取证据，扩展到关联应用与多角色检查。


- [R0010：使用 AI 构建 E2E](../resources/R0010/README.md)：真实浏览器预演与 Playwright 回归，覆盖关键旅程和框架/数据库组合。


- [R0011：AI Coding 深水区](../resources/R0011/README.md)：评测测试本身，并用独立执行核对生产者报告。


- [R0012：AI-native SDLC playbook](../resources/R0012/README.md)：区分任务内反馈与独立最终检查，并结合工具输出和真实结果。

- [R0017：Cloudflare security-audit-skill](../resources/R0017/README.md)：候选由独立验证者尝试反证，最终记录再次复核，结构校验不替代事实验证。

- [R0022：Harness engineering](../resources/R0022/README.md)：每 worktree 应用与可观察栈供 Agent 驱动 UI、查询日志和指标，不以口头汇报代替运行事实。

- [R0025：The end of programming](../resources/R0025/README.md)：真实集群、DuckDB/PyIceberg 与日志指标驱动修错的作者自述；未取得可重放报告，不将“可运行”视作生产验收。

- [R0027：My AI Adoption Journey](../resources/R0027/README.md)：第 2 步经验“给 Agent 验证手段，它多数时候能自己修错”，第 5 步把验证工具列为 harness 的一半；作者自述，无失败率数据。

- [R0029：orbi](../resources/R0029/README.md)：PR 由独立评审会话审查，只有 reviewed head 能合并；属项目自述的机制，未核验强制程度。

- [R0030：Your coding agents made you a manager](../resources/R0030/README.md)：把“给验证手段”列为首要习惯：测试、构建、lint、diff、截图，并要求 Agent 展示结果作为证据。

- [R0031：How the Claude Code team does code review](../resources/R0031/README.md)：六层检查 + 回滚线，多数阅读交给机器；用 revert 与 incident 率防止“省了评审时间、赔了修复时间”。

- [R0033：How the Claude Code team thinks about verification](../resources/R0033/README.md)：把验证拆成 E2E、属性、差分三类测试与 verify 技能，再用 commit gate 的 observe 模式逐步放开；数字属团队自述。

- [R0037：All Code Is Slop (Except Mine)](../resources/R0037/README.md)：代码评审转向看视频、截图、图与 formal verification 结果；发布时自动 fuzz 整个应用并自动合并修复 PR。
